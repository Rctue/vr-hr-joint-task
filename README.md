# Joint action in VR

To investigate joint action a sufficiently complex task is needed where the anticipation of action goals matter from both collaborating agents.
Based on earlier work we developed a cognitive architecture where the robot could infer the goal of a limited set of goals from observing the behaviour of the robot.

An earlier version of this experiment maintained by @jgocunha, which can be found here: https://github.com/Jgocunha/vr-hr-joint-task
This experiment is based off of his work and follows the same installation procedure.
